# Система управління земельним банком (Land Bank Management System)

## 📌 Про проєкт
Цей проєкт являє собою комплексну систему для автоматизації обробки, нормалізації та аналізу даних з державних реєстрів України (ДЗК — Державний земельний кадастр, та ДРРП — Державний реєстр речових прав). 

Головна мета системи — надати агробізнесу потужний інструмент для аудиту земельного банку, виявлення юридичних ризиків, контролю термінів оренди та управління суб'єктами права.

### 🚀 Основні функції
- **Парсинг великих даних:** Обробка масивних JSON-вивантажень (до 400+ МБ) з реєстрів без перевантаження оперативної пам'яті.
- **MDM-словник (Master Data Management):** Автоматична нормалізація "брудних" даних (виправлення помилкових ЄДРПОУ, кодів `00000000`, стандартизація назв компаній) перед записом у базу.
- **Історичність даних (Snapshots):** Збереження історії змін по кожній ділянці (перевірки) без перезапису попередніх станів. Уникнення дублювання завдяки перевірці хеш-сум.
- **Цифрове досьє ділянки:** Об'єднання графічних та технічних даних ДЗК із юридичними правами (власність, оренда, іпотеки, обтяження) та документами-підставами з ДРРП в єдину зручну картку.
- **Аналітичний дашборд:** Багатовимірна аналітика земельного банку в розрізі територій (КОАТУУ / Сільські ради) та конкурентного середовища (по Юридичних особах).

---

## 🛠 Технологічний стек
- **Backend:** Python 3.12, FastAPI (для побудови REST API), Pydantic.
- **Frontend:** Streamlit (для швидкої побудови інтерактивних дашбордів та інтерфейсів), Pandas.
- **База даних:** MS SQL Server, PyODBC (для прямої взаємодії з БД).
- **Інструменти розробки:** `uv` (керування залежностями та віртуальним середовищем), `Ruff` (лінтер та форматер коду), `Loguru` (логування).
